# 01. 노션 작업 DB 만들기
> 붙여 넣는 곳: 노션 커넥터가 켜진 아무 Claude 대화(총괄 대화여도 됨). 아래 블록 하나를 그대로 보낸다.

## 프롬프트 (그대로 복사)
```
노션에 아래 구조로 「한국 부동산 플랫폼 작업」 데이터베이스와 「한국 부동산 플랫폼 허브」 페이지를 만들어라. 다 만들면 데이터베이스 id(32자)와 링크만 알려라.

[허브 페이지] 제목 「한국 부동산 플랫폼 허브」. 안에 하위 페이지 2개: 「규칙」(빈 페이지), 「결정 기록」(빈 페이지). 작업 DB는 허브 안에 둔다.

[작업 DB 속성]
- 이름 (제목) — 형식 「[담당] 할 일 — 요약」
- 담당 (선택): 총괄 · 기획 · 디자인 · 에셋 · 프론트 · 백엔드 · 검수
- 상태 (선택): 시작 전 · 다음 · 진행 중 · 대기 · 완료
- 메모 (텍스트) — 한 줄 현황(착수 시각 · 결과 한 줄 · PR 번호)
- 마감일 (날짜)
- 보낸 쪽 (선택): 운영자 · 총괄 · 직원
- 프로젝트 (텍스트)

[보기 3개]
- 「열린 작업」: 상태 ≠ 완료, 담당별 묶음, 마감일 오름차순
- 「담당별 보드」: 보드, 상태로 묶음
- 「완료」: 상태 = 완료, 최근 수정 순

[레코드 본문 틀] 새 레코드 기본 템플릿 이름 「작업」, 본문:
## 지시
(총괄이 씀 — 목표 · 범위 · 합격 기준 · 하지 말 것 · 마감)
## 결과
(직원이 씀 — 한 일 · 측정값 · 파일/PR 링크 · 남은 것)
## 질문
(직원이 막힐 때만 — 선택지와 가안)
```

## 손으로 만들 때 (프롬프트가 안 될 때)
위 속성 · 보기 · 템플릿을 노션에서 직접 만든다. DB 주소 `notion.so/xxxx?v=yyyy`에서 `xxxx`(32자)가 `{{작업DB_ID}}`다.

## 상태의 뜻 (팀 전체가 이것만 본다)
| 상태 | 뜻 | 누가 바꾸나 |
|---|---|---|
| 시작 전 | 아직 순서 아님 | 총괄 |
| **다음** | 지금 맡아도 됨(직원이 가져감) | 총괄 |
| 진행 중 | 누가 맡아서 하는 중(메모에 「착수 M/D HH:MM」) | 직원 |
| 대기 | 결정 · 다른 일을 기다림(본문 「## 질문」) | 직원 · 총괄 |
| 완료 | 끝 + 결과 기록 + (코드면) PR 링크 | 직원 |

## 노션 통합(토큰) 연결 — 스크립트용
1. notion.so/profile/integrations → 새 통합(내부) → 토큰 복사.
2. 허브 페이지 오른쪽 위 「…」 → 연결 → 방금 만든 통합 추가(작업 DB도 같이 열림).
3. 토큰은 `02`의 환경 변수로만 넣는다. 저장소 · 문서 · 대화에 붙이지 않는다.
