# AI 개발팀 운영 키트 — 웹 · 앱 개발용 (v1)

Claude 여러 대화를 **「총괄 1 + 직원 여럿」 팀**처럼 굴리는 방법이다. 사람(=운영자)은 방향만 정하고, 총괄이 일을 나눠 지시 · 검수 · 머지하며, 직원은 지시를 받아 끝까지 만든다.

## 한 장 요약
```
운영자(나) ──말로 지시──▶ 총괄 대화
                          │  ① 노션 작업 DB에 레코드(지시서) 작성
                          │  ② GitHub 이슈 · 저장소 CLAUDE.md 규칙
                          ▼
   ┌───────────── 노션 작업 DB (유일한 우편함) ─────────────┐
   │ 레코드 = 이름 · 담당 · 상태 · 메모 · 마감일 + 본문(지시/결과/질문) │
   └───────────────────────────────────────────────────┘
        ▲ 맡기 · 결과 기록                 ▲ 맡기 · 결과 기록 · PR
   로컬 직원 대화(기획 · 디자인 · 에셋 · 검수)   클라우드 직원(프론트 · 백엔드 = claude.ai/code)
                                                 │ PR
                                                 ▼
                                   총괄이 검사 확인 → 화면 직접 확인 → main 머지
                                   문제 있으면 「보완 레코드」로 다시 돌림
```
- **대화끼리 직접 말하지 않는다.** 모든 지시 · 결과 · 질문은 노션 레코드에 쓴다. 대화창에는 「작업 끝」 한 줄만.
- **총괄은 직접 만들지 않고, 지시 · 검수 · 머지 · 보고만** 한다(작은 문서 · 설정 · 자산 올리기는 예외).
- **운영자는 결정만** 한다: 방향 · 우선순위 · 돈 드는 것 · 외부 계정 · 배포처 · 마감.

## 준비물
- Claude 데스크톱 앱(Code 탭) — 총괄 · 로컬 직원용. claude.ai의 **Notion 커넥터** 켜기.
- claude.ai/code — 프론트 · 백엔드 클라우드 세션(저장소 연결).
- 노션 워크스페이스 1개, GitHub 조직(또는 개인) 1개, 배포(예: Vercel · Railway · Cloudflare) 계정.
- PC: Git · GitHub CLI(`gh`) · Node 22 LTS · Python(또는 `uv`).

## 바꿔 넣을 값 (모든 파일 공통)
| 표시 | 뜻 | 예 |
|---|---|---|
| `한국 부동산 플랫폼` | 프로젝트 이름 | 「사내 예약 앱」 |
| `{{운영자}}` | 나(결정하는 사람) | 「민수」 |
| `{{고객}}` | 의뢰인(없으면 운영자) | 「A사 담당자」 |
| `{{작업DB_ID}}` | 노션 작업 DB id(32자) | 01번에서 얻음 |
| `choijungman12` | GitHub 조직/계정 | `my-org` |
| `a-real-estate-law` · `a-real-estate-law` | 저장소 이름 | `app-fe` · `app-be` |
| `{{작업폴더}}` | 로컬 작업 폴더 | `C:\Workspace` |

> 팁: 키트 폴더 전체에서 `{{…}}`를 한 번에 바꾸려면 총괄 대화에 「이 폴더의 {{…}} 값을 이렇게 바꿔라: …」라고 하면 된다.

## 첫날 순서 (약 1시간)
1. `01` → 작업 DB 생성, id 메모.
2. `02` → gh 로그인, 노션 토큰 환경 변수, 스크립트 폴더.
3. `03` → 스킬 4개 저장 → Claude 앱 재시작.
4. GitHub에 저장소 2개 만들고 `04`의 CLAUDE.md를 main에 넣는다.
5. `05` → 총괄 대화 시작. `07` · `08` 을 붙여 메모로 저장시킨다.
6. 총괄에게 첫 일을 말한다(예: 「로그인 있는 예약 웹을 만든다. 1차 범위 정해서 레코드 만들어라」).
7. `06` → 직원 대화들을 열어 첫 메시지를 보낸다. 클라우드 세션(프론트 · 백엔드)도 같은 식.
8. 이후 운영자는 「진행상황」 「진행해라」 「○○로 정해라」만 말하면 된다.
